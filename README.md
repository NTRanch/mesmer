# mesmer

mcp-name: io.github.NTRanch/mesmer

A deterministic, consent-gated hypnosis content composer — an MCP
server for Nice Thoughts Ranch apps and games.

Mesmer composes complete hypnosis session packages (induction,
deepener, suggestion body, anchor installation, emergence,
aftercare), layered subliminal editions, and longitudinal
conditioning programmes as data for the estate's runtime engine
to render. Composition is seeded and reproducible: the same
request and seed yield the byte-identical package.

Consent is the server's spine, not a feature. Nothing is
generated outside a consent profile the user created for
herself; the profile's envelope bounds every class, intensity,
and grant; and a full disclosure log records everything
delivered. The design is specified in `docs/PLAN.md`.

Status: production 1.1.0, 2026-11-27 — canon, the consent gate,
theme-pack delivery (bimbo glamour; subliminal submissive
training), the standard engagement trigger, playlists with
typed compounding, composite delivery, and concurrent sessions.
Deployed on primo as a socket-activated systemd user service
(`mesmer.socket` / `mesmer@.service`); the binary is
`~/.local/bin/mesmer`.
